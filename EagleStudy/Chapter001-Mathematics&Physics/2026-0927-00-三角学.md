# 三角学

## 1. 什么是三角学

**三角学（Trigonometry）**是研究：

* 角
* 三角形
* 边长之间的关系
* 角与长度之间的数量关系

的一门数学。

它最初主要研究三角形，但现代三角学已经扩展到：

* 圆
* 周期运动
* 波
* 空间几何
* 坐标系
* 物理学
* 工程学
* 计算机图形学
* 游戏开发

其中最核心的思想可以概括为：

> **用角度描述方向，用三角函数描述角度与长度之间的关系。**

---

# 2. 三角学的基础：角

## 2.1 什么是角

角可以理解为：

> **一条射线绕着一个固定点旋转所形成的张角。**

角通常用希腊字母表示，例如：

* `θ`：theta
* `α`：alpha
* `β`：beta
* `φ`：phi

例如：

```text
θ = 30°
```

表示角 `θ` 为 30 度。

---

# 3. 角度的两种单位

## 3.1 角度制

最常见的是度数：

```text
90°
180°
270°
360°
```

完整旋转一周：

```text
360°
```

---

## 3.2 弧度制

数学和程序开发中经常使用**弧度**。

完整一周：

```text
2π
```

因此：

```text
360° = 2π
180° = π
90°  = π/2
60°  = π/3
45°  = π/4
30°  = π/6
```

角度和弧度之间：

```text
弧度 = 角度 × π / 180
```

例如：

```text
60° = 60 × π / 180
   = π/3
```

---

# 4. 三角形

三角形有三个角和三条边。

三角形内角和：

```text
A + B + C = 180°
```

或者用弧度表示：

```text
A + B + C = π
```

---

# 5. 直角三角形

三角学最重要的起点是：

> **直角三角形。**

直角三角形具有一个 `90°` 的角。

相对于某一个锐角 `θ`，三条边分别叫：

* **斜边**：直角对面的边
* **对边**：`θ` 对面的边
* **邻边**：与 `θ` 相邻、但不是斜边的边

---

# 6. 勾股定理

对于直角三角形：

```text
a² + b² = c²
```

其中：

* `a`：一条直角边
* `b`：另一条直角边
* `c`：斜边

例如：

```text
3² + 4² = 5²
```

因为：

```text
9 + 16 = 25
```

所以 `3、4、5` 可以组成直角三角形。

---

# 7. 三角函数

三角学最核心的三个函数是：

```text
sin
cos
tan
```

它们分别是：

```text
正弦
余弦
正切
```

对于角 `θ`：

```text
sin θ = 对边 / 斜边

cos θ = 邻边 / 斜边

tan θ = 对边 / 邻边
```

可以记忆为：

```text
SOH
CAH
TOA
```

即：

```text
S = O / H
C = A / H
T = O / A
```

---

# 8. 正弦

正弦定义为：

```text
sin θ = 对边 / 斜边
```

如果：

```text
对边 = 3
斜边 = 5
```

那么：

```text
sin θ = 3/5 = 0.6
```

因此正弦本质上是在回答：

> **这个角对应的“高度方向”占斜边的多少？**

---

# 9. 余弦

余弦定义为：

```text
cos θ = 邻边 / 斜边
```

例如：

```text
邻边 = 4
斜边 = 5
```

那么：

```text
cos θ = 4/5 = 0.8
```

余弦可以理解为：

> **这个角对应的“水平方向”占斜边的多少？**

---

# 10. 正切

正切定义为：

```text
tan θ = 对边 / 邻边
```

例如：

```text
对边 = 3
邻边 = 4
```

那么：

```text
tan θ = 3/4 = 0.75
```

正切特别适合描述：

> **一个方向有多“陡”。**

例如斜率：

```text
斜率 = 高度变化 / 水平变化
```

这与正切完全对应：

```text
tan θ = 高度变化 / 水平变化
```

---

# 11. 三角函数之间的关系

正切可以由正弦和余弦得到：

```text
tan θ = sin θ / cos θ
```

因为：

```text
sin θ = 对边 / 斜边
cos θ = 邻边 / 斜边
```

所以：

```text
sin θ / cos θ

= (对边 / 斜边) / (邻边 / 斜边)

= 对边 / 邻边

= tan θ
```

---

# 12. 最重要的三角恒等式

三角学中最重要的恒等式之一：

```text
sin²θ + cos²θ = 1
```

它实际上来源于勾股定理。

假设：

```text
sin θ = a/c
cos θ = b/c
```

那么：

```text
sin²θ + cos²θ

= a²/c² + b²/c²

= (a² + b²)/c²
```

根据勾股定理：

```text
a² + b² = c²
```

所以：

```text
sin²θ + cos²θ
= c²/c²
= 1
```

这说明：

> **三角函数与几何中的勾股定理实际上是同一个结构。**

---

# 13. 单位圆

三角学从直角三角形继续发展，就会进入一个非常重要的概念：

> **单位圆。**

单位圆就是半径为 `1` 的圆。

它的方程是：

```text
x² + y² = 1
```

在单位圆上，一个角 `θ` 对应一个点：

```text
(x, y)
```

这个点满足：

```text
x = cos θ

y = sin θ
```

因此：

```text
(cos θ, sin θ)
```

就是单位圆上角度 `θ` 对应的点。

这一步非常重要，因为它把：

```text
三角形
```

扩展到了：

```text
整个圆
```

---

# 14. 为什么正弦和余弦会出现负数

在直角三角形中，我们通常只研究锐角，因此：

```text
sin θ > 0
cos θ > 0
```

但是单位圆允许角度继续旋转。

于是会进入不同象限。

## 第一象限

```text
sin θ > 0
cos θ > 0
```

## 第二象限

```text
sin θ > 0
cos θ < 0
```

## 第三象限

```text
sin θ < 0
cos θ < 0
```

## 第四象限

```text
sin θ < 0
cos θ > 0
```

因此三角函数不仅可以描述三角形，还可以描述：

> **一个方向在二维空间中的位置。**

# 15. 常见角度

最常用的特殊角：

|     角度 |     弧度 |
| -----: | -----: |
|   `0°` |    `0` |
|  `30°` |  `π/6` |
|  `45°` |  `π/4` |
|  `60°` |  `π/3` |
|  `90°` |  `π/2` |
| `180°` |    `π` |
| `270°` | `3π/2` |
| `360°` |   `2π` |

其中：

```text
sin 0° = 0
cos 0° = 1

sin 30° = 1/2
cos 30° = √3/2

sin 45° = √2/2
cos 45° = √2/2

sin 60° = √3/2
cos 60° = 1/2

sin 90° = 1
cos 90° = 0
```

# 16. 三角函数图像

当角度不断增加时：

```text
sin θ
```

会不断在：

```text
-1
```

和：

```text
1
```

之间变化。

因此正弦是一种**周期函数**。

它满足：

```text
sin(θ + 2π) = sin θ
```

余弦同样满足：

```text
cos(θ + 2π) = cos θ
```

正切的周期则是：

```text
tan(θ + π) = tan θ
```

所以三角函数天然适合描述：

* 波动
* 振动
* 圆周运动
* 周期运动
* 往复运动

---

# 17. 三角函数与坐标系

三角学与笛卡尔坐标系关系非常密切。

给定一个方向：

```text
θ
```

如果一个向量长度为：

```text
r
```

那么它在二维坐标系中的分量为：

```text
x = r cos θ

y = r sin θ
```

因此一个二维向量可以表示为：

```text
v = (r cos θ, r sin θ)
```

反过来，如果知道：

```text
x
y
```

那么向量长度：

```text
r = √(x² + y²)
```

方向可以通过反正切求出：

```text
θ = atan2(y, x)
```

这就是三角学与计算机图形学之间非常重要的连接。

---

# 18. 反三角函数

如果已知三角函数值，可以反过来求角度。

例如：

```text
sin θ = 0.5
```

可以使用：

```text
θ = arcsin(0.5)
```

得到：

```text
θ = 30°
```

常见反三角函数：

```text
arcsin
arccos
arctan
```

程序中通常写成：

```text
asin
acos
atan
```

以及更常用的：

```text
atan2(y, x)
```

---

# 19. 三角学解决什么问题

假设你知道：

```text
一个物体距离你 10 米
```

并且它位于：

```text
30°
```

方向。

那么可以计算它相对于你的水平和垂直方向的位置。

例如：

```text
x = 10 cos 30°

y = 10 sin 30°
```

于是：

```text
x = 5√3

y = 5
```

也就是说：

> **三角函数可以把“长度 + 方向”转换成“坐标”。**

反过来：

> **三角函数也可以把“坐标”转换成“长度 + 方向”。**

这就是三角学非常核心的用途。

# 20. 三角学与游戏开发

对于 2D、3D 游戏开发，三角学非常重要。

例如：

## 角色朝向

已知角色与目标之间：

```text
方向 = target - player
```

可以通过：

```text
atan2
```

求出水平旋转角。

---

## 子弹方向

如果知道：

```text
角度 θ
```

可以计算方向：

```text
direction.x = cos θ

direction.y = sin θ
```

然后让子弹沿这个方向运动。

---

## 圆周运动

如果一个物体围绕中心旋转：

```text
x = center.x + radius × cos θ

y = center.y + radius × sin θ
```

就可以得到圆周上的位置。

---

## 3D 游戏

在 3D 中，三角学还可以用于：

* 摄像机旋转
* 角色朝向
* 炮塔瞄准
* 子弹散射
* 视野计算
* 圆周运动
* 波浪运动
* 光照计算
* 法线计算
* 球形运动
