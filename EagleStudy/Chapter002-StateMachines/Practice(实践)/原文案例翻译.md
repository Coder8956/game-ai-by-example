## 补充：原文中的口语表达

图片中的鲍勃使用了带有美国西部矿工风格的非正式口语拼写。

| 原文表达     | 标准形式             | 中文含义       |
| -------- | ---------------- | ---------- |
| Pickin'  | Picking          | 捡起、拾取      |
| Ah'm     | I'm              | 我是、我要      |
| leavin'  | leaving          | 离开         |
| mah      | my               | 我的         |
| o'       | of               | ……的        |
| Goin'    | Going            | 去、前往       |
| Walkin'  | Walking          | 行走         |
| thusty   | thirsty（疑似方言化拼写） | 口渴的        |
| saloon   | saloon           | 西部酒馆       |
| siree    | sir（口语强调）        | 当然、没错      |
| li'l     | little           | 小的         |
| God-darn | God-damned 的委婉表达 | 该死的、真是……极了 |

说明： `nugget` 在这里指金块或天然金粒；`Total savings now` 表示当前累计存款。原文中的 `ZZZZ...` 是表示人物睡觉的拟声符号。
