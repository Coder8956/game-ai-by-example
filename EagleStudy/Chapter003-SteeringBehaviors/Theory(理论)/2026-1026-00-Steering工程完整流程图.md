# Steering 工程完整流程图（Buckland 第三章 · Steering Behaviors）

> 工程位置：`Buckland_Chapter3-Steering Behaviors/Steering.sln`
> 本文档基于对全部源码（`main.cpp`、`GameWorld.h/.cpp`、`Vehicle.h/.cpp`、`SteeringBehaviors.h/.cpp`、`MovingEntity.h`、`BaseGameEntity.h`、`Obstacle.h/.cpp`、`Path.h/.cpp`、`ParamLoader.h/.cpp`、`EntityFunctionTemplates.h`、`constants.h`、`params.ini`）的通读整理。
>
> 一句话理解本工程：**一个 Windows 图形窗口程序，300 辆"小鱼"机器人通过 16 种转向行为在屏幕上成群飞行**，最后一辆被改造成巨大的"鲨鱼"，其余小鱼全部开启"逃命"行为躲着它。核心是每帧循环执行 **"行为 → 转向力 → 合力 → 加速度 → 速度 → 位置"** 的物理循环。

## 3. 程序启动流程（WinMain）

```mermaid
flowchart TD
    A[WinMain 入口] --> B[填充 WNDCLASSEX 窗口类结构]
    B --> C[RegisterClassEx 注册窗口类]
    C --> D{注册成功?}
    D -- 否 --> E[MessageBox 报错<br/>返回 0 退出]
    D -- 是 --> F[CreateWindowEx 创建窗口<br/>尺寸取 constants.h 500×500]
    F --> G{窗口句柄有效?}
    G -- 否 --> H[MessageBox 报错]
    G -- 是 --> I[ShowWindow 显示窗口]
    I --> J[UpdateWindow 立即刷新一次]
    J --> K[创建 PrecisionTimer 高精度计时器<br/>并开启平滑更新 SmoothUpdatesOn]
    K --> L[创建 MSG 消息结构]
    L --> M[进入主消息循环]

    M --> N[PeekMessage 取出消息]
    N --> O{取到消息?}
    O -- 是 --> P{消息是 WM_QUIT?}
    P -- 是 --> Q[置 bDone = true]
    P -- 否 --> R[TranslateMessage 翻译]
    R --> S[DispatchMessage 分发到 WindowProc]
    S --> T[回到循环顶部]
    O -- 否 --> U{msg 不是 WM_QUIT?}
    U -- 是 --> V["★ g_GameWorld->Update(timer.TimeElapsed)<br/>每帧更新整个世界"]
    V --> W[RedrawWindow 请求重绘<br/>触发 WM_PAINT → Render]
    W --> X[Sleep 2ms 让出 CPU]
    X --> M
    U -- 否 --> M

    Q --> Y[退出循环]
    Y --> Z[delete g_GameWorld 释放世界]
    Z --> AA[UnregisterClass 注销窗口类]
    AA --> AB[返回 msg.wParam 退出码]
```

**要点**：窗口创建时会先收到 `WM_CREATE` 消息（见下一节），在那里完成后备缓冲创建与 `GameWorld` 的构建；之后主循环每帧交替执行 **取消息 → 更新世界 → 请求重绘**。

## 6. 主循环单帧运行流程

这是整个工程的心脏：**每帧（约每 2ms 节流一次）驱动所有机器人移动**。

```mermaid
flowchart TD
    A[GameWorld::Update time_elapsed] --> B{暂停 m_bPaused?}
    B -- 是 --> END[直接返回，画面冻结]
    B -- 否 --> C[帧率平滑：Smoother取最近10帧<br/>算平均帧耗时 m_dAvFrameTime 用于显示FPS]
    C --> D[for 遍历 m_Vehicles 所有机器人]
    D --> E[Vehicle::Update time_elapsed]

    E --> E1[记录本帧时间 m_dTimeElapsed<br/>供徘徊行为按时间缩放抖动]
    E1 --> E2[记录旧位置 OldPos<br/>供网格更新用]
    E2 --> E3[★ SteeringForce = m_pSteering->Calculate<br/>计算总转向力]
    E3 --> E4[加速度 = 转向力 ÷ 质量<br/>牛顿第二定律 F=ma]
    E4 --> E5[速度 += 加速度 × time]
    E5 --> E6[速度 Truncate 截断到 MaxSpeed 限速]
    E6 --> E7[位置 += 速度 × time]
    E7 --> E8{速度非零?}
    E8 -- 是 --> E9[朝向 = 归一化速度<br/>侧向 = 朝向.Perp 垂直方向]
    E8 -- 否 --> E10[保持原朝向]
    E9 --> E10
    E10 --> E11[WrapAround 屏幕环绕<br/>把屏幕当甜甜圈，出界从对面钻回]
    E11 --> E12{网格划分开着?}
    E12 -- 是 --> E13[CellSpace->UpdateEntity 更新所在格子]
    E12 -- 否 --> E14
    E13 --> E14{朝向平滑开着?}
    E14 -- 是 --> E15[平滑朝向 = Smoother 取最近N帧平均]
    E14 -- 否 --> E16[Vehicle::Update 结束]
    E15 --> E16

    E16 --> F{所有机器人更新完?}
    F -- 否 --> D
    F -- 是 --> G[GameWorld::Update 结束]
```

## 7. 转向力计算流程（SteeringBehavior::Calculate）

`Vehicle::Update` 每帧调用它一次，返回"总转向力"。

```mermaid
flowchart TD
    A[SteeringBehavior::Calculate 入口] --> B[清零旧力 m_vSteeringForce.Zero]
    B --> C{网格划分 isSpacePartitioningOn?}

    C -- 否 --> D{分离/对齐/内聚 任一开着?}
    D -- 是 --> D1[World->TagVehiclesWithinViewRange<br/>给视野 ViewDistance 内机器人打标记]
    D -- 否 --> F

    C -- 是 --> E{分离/对齐/内聚 任一开着?}
    E -- 是 --> E1[World->CellSpace->CalculateNeighbors<br/>网格计算邻居存进迭代器]
    E -- 否 --> F

    D1 --> F
    E1 --> F

    F{switch 合力方式 m_SummingMethod}
    F -- weighted_average 加权平均 --> G1[CalculateWeightedSum<br/>所有行为力×权重相加 → Truncate截断]
    F -- prioritized 优先级 --> G2[CalculatePrioritized<br/>按优先级逐个加，额度用尽即停]
    F -- dithered 抖动 --> G3[CalculateDithered<br/>每帧按概率随机抽行为出力]

    G1 --> H[返回 m_vSteeringForce 总转向力]
    G2 --> H
    G3 --> H
```

## 8. 三种合力合成方式

### 8.1 优先级合成法（默认，CalculatePrioritized）

**处理顺序 = 行为重要程度从高到低**；每个行为算出力后累加，一旦 `AccumulateForce` 判定"额度用尽"立刻返回，后面的低优先级行为不再参与。

```mermaid
flowchart TD
    A[CalculatePrioritized 入口] --> B{避墙开着?}
    B -- 是 --> B1[WallAvoidance × 权重 → AccumulateForce]
    B1 --> B2{额度用尽?}
    B2 -- 是 --> RET[提前返回]
    B2 -- 否 --> C
    B -- 否 --> C

    C{避障开着?} -- 是 --> C1[ObstacleAvoidance × 权重 → 累加]
    C1 --> C2{额度用尽?}
    C2 -- 是 --> RET
    C2 -- 否 --> D
    C -- 否 --> D

    D{逃命开着?} -- 是 --> D1[Evade × 权重 → 累加<br/>断言目标已指定]
    D1 --> D2{额度用尽?}
    D2 -- 是 --> RET
    D2 -- 否 --> E
    D -- 否 --> E

    E{逃离开着?} -- 是 --> E1[Flee 十字准星反方向 × 权重 → 累加]
    E1 --> E2{额度用尽?}
    E2 -- 是 --> RET
    E2 -- 否 --> F
    E -- 否 --> F

    F{网格没开?} -- 是 --> G1[分离 Separation → 对齐 Alignment → 内聚 Cohesion<br/>逐个×权重累加，额度用尽即停]
    F -- 否 --> G2[分离Plus → 对齐Plus → 内聚Plus<br/>网格版邻居，逐个累加]

    G1 --> H
    G2 --> H

    H{追击开着?} -- 是 --> H1[Seek 十字准星 × 权重 → 累加]
    H1 --> H2{额度用尽?}
    H2 -- 是 --> RET
    H2 -- 否 --> I
    H -- 否 --> I

    I{到达开着?} -- 是 --> I1[Arrive 十字准星 × 权重 → 累加]
    I1 --> I2{额度用尽?}
    I2 -- 是 --> RET
    I2 -- 否 --> J
    I -- 否 --> J

    J{徘徊开着?} -- 是 --> J1[Wander × 权重 → 累加]
    J1 --> J2{额度用尽?}
    J2 -- 是 --> RET
    J2 -- 否 --> K
    J -- 否 --> K

    K{拦截开着?} -- 是 --> K1[Pursuit × 权重 → 累加<br/>断言目标]
    K1 --> K2{额度用尽?}
    K2 -- 是 --> RET
    K2 -- 否 --> L
    K -- 否 --> L

    L{编队追击开着?} -- 是 --> L1[OffsetPursuit 无权重 → 累加<br/>断言队长与偏移]
    L1 --> L2{额度用尽?}
    L2 -- 是 --> RET
    L2 -- 否 --> M
    L -- 否 --> M

    M{插到中间开着?} -- 是 --> M1[Interpose × 权重 → 累加<br/>断言两目标]
    M1 --> M2{额度用尽?}
    M2 -- 是 --> RET
    M2 -- 否 --> N
    M -- 否 --> N

    N{躲藏开着?} -- 是 --> N1[Hide × 权重 → 累加<br/>断言猎人]
    N1 --> N2{额度用尽?}
    N2 -- 是 --> RET
    N2 -- 否 --> O
    N -- 否 --> O

    O{沿路径开着?} -- 是 --> O1[FollowPath × 权重 → 累加]
    O1 --> O2{额度用尽?}
    O2 -- 是 --> RET
    O2 -- 否 --> P
    O -- 否 --> P

    P[返回 m_vSteeringForce 总转向力]
    RET[提前返回当前已累加的总力]
```

> 权重来自 `params.ini`（经 `Prm.SteeringForceTweaker` 缩放）。`AccumulateForce` 保证总力不超过车辆 `MaxForce`。

### 8.2 加权平均法（CalculateWeightedSum）

```mermaid
flowchart LR
    A[CalculateWeightedSum 入口] --> B[所有开着的行为<br/>避墙/避障/逃命/群体三件套/徘徊/追击/逃离/到达/拦截/编队/插中/躲藏/沿路径]
    B --> C[各自 力×权重 全部相加<br/>不设优先级、不中途退出]
    C --> D[最后 Truncate 总力截断到 MaxForce]
    D --> E[返回总转向力]
```

### 8.3 抖动合成法（CalculateDithered）

```mermaid
flowchart TD
    A[CalculateDithered 入口] --> B[清零总力]
    B --> C[按优先级顺序逐个行为<br/>避墙→避障→分离→逃离→逃命→对齐→内聚→徘徊→追击→到达]
    C --> D{该行为开着 且<br/>RandFloat < Prm.prXxx 概率命中?}
    D -- 否 --> C
    D -- 是 --> E[力×权重÷概率 期望补偿]
    E --> F{力非零?}
    F -- 是 --> G[Truncate 截断]
    G --> H[直接返回，其余行为本帧不参与]
    F -- 否 --> C
    C --> I[全部轮完仍无命中 → 返回零向量]
```

## 9. 16 个转向行为算法一览

每个行为算法返回一个"转向力向量"，核心公式是 **转向力 = 期望速度 − 当前速度**（速度差）。

```mermaid
flowchart TD
    subgraph 单体行为
        SEEK[Seek 追击<br/>目标：十字准星<br/>期望速度=朝目标单位向量×最大速度<br/>力=期望速度−当前速度]
        FLEE[Flee 逃离<br/>目标：十字准星<br/>朝反方向全速跑]
        ARRIVE["Arrive 到达<br/>接近目标按减速档减速<br/>speed=距离÷(档位×0.3)，封顶MaxSpeed"]
        WANDER[Wander 徘徊<br/>车前方徘徊圆上的目标点<br/>每帧随机抖动→投影回圆→朝它转向]
    end

    subgraph 预测类行为
        PURSUIT[Pursuit 拦截<br/>猎物在前方且迎面<18°→Seek当前位置<br/>否则预测未来位置：距离÷速度之和×速度]
        EVADE[Evade 逃命<br/>威胁范围100内<br/>Flee 追兵未来位置]
        INTERPOSE[Interpose 插中<br/>算两目标当前中点→估到达时间T<br/>预测T后未来中点→Arrive]
        OFFSET[OffsetPursuit 编队追击<br/>偏移向量变换到队长世界坐标<br/>预测未来偏移点→Arrive]
    end

    subgraph 环境避让
        OBST[ObstacleAvoidance 避障<br/>检测盒长度随速度增长<br/>盒内障碍变换到车头系→找最近交点<br/>侧向推离力+制动力]
        WALL[WallAvoidance 避墙<br/>3根触须：正前全长+左右半长45°<br/>触须穿墙→沿墙法线×越界量推力]
    end

    subgraph 群体行为 flocking
        SEP[Separation 分离<br/>力=Σ归一化背向邻居向量÷距离<br/>越近越排斥]
        ALI[Alignment 对齐<br/>力=邻居平均朝向−自己朝向]
        COH[Cohesion 内聚<br/>力=归一化 Seek 邻居重心]
    end

    subgraph 路径与躲藏
        FP[FollowPath 沿路径<br/>距当前路标点<20px切换下一个<br/>有路标→Seek；最后一个→Arrive]
        HIDE[Hide 躲藏<br/>每个障碍算背对猎人的藏身点<br/>选最近→Arrive；无障碍→Evade]
    end

    subgraph 网格版群体行为
        SEPP[SeparationPlus]
        ALIP[AlignmentPlus]
        COHP[CohesionPlus]
    end

    SEP -.开启网格时等价替换.-> SEPP
    ALI -.开启网格时等价替换.-> ALIP
    COH -.开启网格时等价替换.-> COHP
```

**行为开关位表**（`m_iFlags` 一个 int 的 16 个位）：

| 位 | 行为 | 位 | 行为 |
|---|---|---|---|
| 0x00002 | seek 追击 | 0x00800 | pursuit 拦截 |
| 0x00004 | flee 逃离 | 0x01000 | evade 逃命 |
| 0x00008 | arrive 到达 | 0x02000 | interpose 插中 |
| 0x00010 | wander 徘徊 | 0x04000 | hide 躲藏 |
| 0x00020 | cohesion 内聚 | 0x08000 | flock 群体飞行组合 |
| 0x00040 | separation 分离 | 0x10000 | offset_pursuit 编队追击 |
| 0x00080 | allignment 对齐 | — | — |
| 0x00100 | obstacle_avoidance 避障 | — | — |
| 0x00200 | wall_avoidance 避墙 | — | — |
| 0x00400 | follow_path 沿路径 | — | — |

## 10. 渲染流程

```mermaid
flowchart TD
    A[WM_PAINT 触发] --> B[BitBlt 刷白后备缓冲]
    B --> C[gdi->StartDrawing 开始绘图]
    C --> D[GameWorld::Render]

    D2 --> D3[for 遍历所有机器人 → Vehicle::Render]
    D3 --> D4[选颜色<br/>邻居着色开：头车红/邻居绿/其余蓝<br/>插中行为红 / 躲藏行为绿]
    D4 --> D5[WorldTransform 本地三角形顶点<br/>变换到世界坐标<br/>平滑开用平滑朝向，否则用瞬时朝向]
    D5 --> D6[gdi->ClosedShape 画三角形小车]
    D6 --> D7{显示按键帮助 ViewKeys?}
    D7 -- 是 --> D8[Steering->RenderAids<br/>参数面板/转向力箭头/徘徊圆/检测盒/触须/路径<br/>权重实时调节 S-X/A-Z/D-C 等]
    D7 -- 否 --> D3

    D3 --> D9[网格信息开且头车：<br/>画视野方框+红圈邻居+绿圈视野]
    D9 --> D10[显示路径：底部提示 + Path::Render 橙色连线]
    D10 --> D11[显示FPS：1÷平均帧耗时 左下角]
    D11 --> D12[网格信息开：CellSpace->RenderCells 画网格线]

    D12 --> E[gdi->StopDrawing]
    E --> F[BitBlt SRCCOPY 后备缓冲翻到屏幕]
    F --> G[画面呈现，无闪烁]
```
